# 대본 작성 규칙

1편과 2편을 만들고 나서 운영자가 **"AI스럽다, 귀에 안 들어온다"**고 했다 (2026-09-21).
감이 아니라 세어 보고 원인을 찾았다. 그 결과를 규칙으로 남긴다.

`config/app.json`의 `script` 블록이 아래 항목 일부를 자동으로 검사한다.
`python main.py --input ... --validate-only`에서 경고로 나온다.

## 무엇이 문제였나

| 항목 | 1편 | 2편 |
|---|---|---|
| 실제 대사가 있는 씬 | **0 / 8** | **0 / 8** |
| 주어가 생략된 문장 | 5 / 8 | **8 / 8** |
| 지시어가 있는 씬 | 3 / 8 | **5 / 8** |

두 대본 모두 **사람이 뱉는 말이 한 줄도 없었다.** 8씬 전부가 화자의 해설이다.

> 1편 SCENE-05 — "듣는 사람은 거절이 아니라 선긋기로 받아들여요"
> 2편 SCENE-05 — "넘긴 사람은 오늘 안에 된다고 생각해요"

직장인 공감 콘텐츠인데 사무실 장면이 안 보이고 논평만 들린다.
글로 읽으면 말이 되지만, TTS가 읽으면 **누가 누구한테 하는 얘긴지 잡히지 않는다.**

## 규칙

### 1. 실제 대사를 최소 3씬에 넣는다

해설하지 말고 그 사람이 한 말을 따옴표 안에 그대로 넣는다.
공감이 걸리는 건 논평이 아니라 대사다.

- ✕ 넘긴 사람은 오늘 안에 된다고 생각해요.
- ○ 다음 날 물어보니까 이러시더라고요. **"어, 그거 급한 거 아니었는데."**

### 2. 주어를 고정한다

한 편 안에서 **"저"와 상대 한 명**으로 고정한다. 문장마다 주어가 바뀌면
음성으로 들을 때 누구 얘긴지 계속 재구성해야 한다.

1편은 문장 첫머리가 이랬다 —
`(생략) / 팀장님이 / (생략) / (생략) / 듣는 / (생략) / 거절은 / (생략)`

### 3. 지시어를 쓰지 않는다

"이 말", "이것", "이걸", "그때"는 **가리키는 대상이 이미 나온 뒤에만** 쓸 수 있다.
음성은 되돌려 들을 수 없다.

2편은 훅(SCENE-01)에서 "이 말만 하고 끝내면"이라고 했는데
그 말이 무엇인지는 SCENE-03에서야 나온다. 두 씬 동안 시청자는 모르는 채로 듣는다.

**훅에서는 그 말을 바로 들려준다.**

- ✕ 회사에서 이 말만 하고 끝내면, 야근은 확정입니다.
- ○ **"네, 알겠습니다."** 이 한마디 때문에 그날 밤 열한 시까지 남았어요.

### 4. 손해를 숫자와 그림으로 말한다

추상명사로 끝맺지 않는다. 들었을 때 장면이 떠올라야 한다.

- ✕ 야근은 확정입니다 / 판단은 상대에게 넘어갑니다 / 태도로 전달됩니다
- ○ 그날 밤 열한 시까지 남았어요 / 오늘 밤이 모레 오전이 되기도 해요

### 5. 말하는 어미를 쓴다

TTS는 문어체를 그대로 낭독한다. AI스럽게 들리는 지점이 대개 여기다.

| 쓰지 않는다 | 쓴다 |
|---|---|
| 빠져 있습니다 | 안 물어봤어요 |
| 전달됩니다 | 그렇게 들려요 |
| 받아들여집니다 | 그렇게 받아들이더라고요 |
| ~하는 것이 좋습니다 | ~해보세요 |

### 6. 같은 내용을 두 씬에 나눠 쓰지 않는다

2편의 SCENE-04(언제까지가 빠졌다)와 SCENE-05(상대는 오늘로 안다)는 같은 정보다.
37초짜리에서 7초를 중복에 썼다.

8씬 템플릿(훅 / 상황 / 공감 / 문제 / 반응 / 해결 / 적용 / 마무리)을 기계적으로 채우면
'문제'와 '반응'이 같은 말이 되기 쉽다. 틀을 채우지 말고 **이야기를 진행시킨다.**

### 7. 한 씬은 60자 이하

길면 자막이 넘치고 화면이 정체된다.

## 쓰고 나서 확인

```bash
python main.py --input ./inputs/YYYY-MM-DD --validate-only
```

경고가 나오면 고친다. 경고는 강제가 아니다 — 의도한 것이면 그대로 두되,
**왜 그랬는지 설명할 수 있어야 한다.**

기준을 조정하려면 `config/app.json`의 `script` 블록을 고친다.

## 적용 이력

- **1편 / 2편** — 위 규칙 이전에 만들었다. 이미 업로드돼 있어 고치지 않는다.
- **3편부터** 이 규칙을 적용한다.
