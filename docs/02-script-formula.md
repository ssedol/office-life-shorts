# 02. 대본 공식

모든 대본은 **초 단위 블록**으로 쓴다. "대충 45초 분량" 같은 건 없다.

## 0. 공통 골격 (45초 기준)

```
[0.0 ~ 3.0]   HOOK      ─ 이탈 저지. 여기서 절반이 결정된다.
[3.0 ~ 8.0]   SETUP     ─ 시청자 머릿속에 장면을 세운다.
[8.0 ~ 30.0]  BODY      ─ 축별로 형태가 다름 (아래)
[30.0 ~ 40.0] PAYOFF    ─ 반전 / 핵심 한 문장 / 위로
[40.0 ~ 45.0] CTA       ─ 댓글 유도 질문
```

### 낭독 속도 기준
한국어 쇼츠 나레이션은 **초당 4.5~5.5자**가 편하게 들리는 구간이다(공백 제외).
→ 45초 영상 = **약 210~240자**. 이걸 넘으면 말이 빨라지고, 모자라면 늘어진다.
대본 작성 후 반드시 글자수를 센다.

---

## 1. 공감형 (A축) — "상황 재현 3단"

시청자가 자기 회사를 떠올리게 만드는 게 전부다. 설명하지 말고 **중계**한다.

```
[0~3]   HOOK   : 시간·장소·인물을 박아버린다
                 "월요일 오전 9시 12분. 팀장이 모니터 보면서 한숨 쉬면"
[3~8]   SETUP  : 시청자를 그 자리에 앉힌다
                 "그때 절대 먼저 말 걸면 안 돼요. 왜냐면"
[8~30]  BODY   : 단계 3개로 쪼갠다 (1단계 → 2단계 → 3단계)
                 각 단계는 6~8초. 뒤로 갈수록 강도가 올라간다.
                 1단계: 누구나 아는 것
                 2단계: 겪어본 사람만 아는 것   ← 여기서 "어 맞아" 나옴
                 3단계: 말 안 하던 것           ← 여기서 댓글 나옴
[30~40] PAYOFF : 반전 또는 뼈 있는 한 줄
                 "근데 사실 그 한숨, 팀장도 위에서 깨지고 온 거예요"
[40~45] CTA    : "여러분 팀장은 몇 단계까지 가요?"
```

**공감형 체크**: 이 대본을 읽고 시청자가 **특정 인물 한 명**을 떠올릴 수 있는가? 못 떠올리면 디테일이 부족한 것이다.

---

## 2. 꿀팁형 (B축) — "손해 → 해법 3스텝"

정보를 주는 게 아니라 **내일 아침에 쓸 행동 하나**를 준다.

```
[0~3]   HOOK   : 손해 경고형
                 "보고서 반려 계속 당하는 사람, 내용 문제 아니에요"
[3~8]   SETUP  : 흔한 오답을 먼저 죽인다
                 "다들 내용을 더 채우려고 하는데, 그럴수록 더 반려돼요"
[8~30]  BODY   : 실행 스텝 3개. 각 7초.
                 스텝마다 "무엇을" + "어떻게" 를 같이 준다.
                 ❌ "결론부터 쓰세요"        ← 뻔함
                 ✅ "첫 줄에 '결론: ~하겠습니다' 를 그냥 박아버리세요"  ← 복붙 가능
[30~40] PAYOFF : 왜 먹히는지 한 줄 이유 (여기 심리학 각주 1줄 가능)
                 "팀장은 읽을 시간이 없어서 반려하는 거지, 부족해서가 아니거든요"
[40~45] CTA    : "이거 쓰고 한 번에 통과된 사람 댓글 남겨주세요"
```

**꿀팁형 체크**: 시청자가 **내일 9시에 그대로 복사해서 쓸 수 있는가?** 추상적이면 실패.

---

## 3. 정보형 (C축) — "손해 → 숫자 → 조건"

법·제도·급여. **숫자와 조건이 핵심**이고, 틀리면 안 된다.

```
[0~3]   HOOK   : 금액 또는 손해 명시
                 "연차 안 쓰고 퇴사하면, 그 연차 돈으로 받을 수 있어요"
[3~8]   SETUP  : 오해 정정
                 "쓰라고 했는데 안 썼으니 소멸이라고요? 조건 따라 달라요"
[8~30]  BODY   : ① 원칙 ② 예외/조건 ③ 실제 행동
                 반드시 근거 조문·기관명을 자막에 노출
[30~40] PAYOFF : 한 줄 요약 + 확인 경로
                 "본인 상황은 고용노동부 1350에서 무료로 확인돼요"
[40~45] CTA    : "이거 몰라서 못 받은 사람 있으면 댓글로"
```

**정보형 필수 규칙**
- 대본 하단에 **출처 표기** (법령명 + 조항 / 기관 페이지). `templates/script.md`의 출처란은 비워두고 업로드 금지.
- 영상 내 자막에 "개인 상황에 따라 다를 수 있음" 1회 노출.
- 애매하면 만들지 않는다. **정보형은 안 만들어도 채널이 안 죽지만, 틀리면 죽는다.**

---

## 4. CTA 규칙

**"구독·좋아요 부탁드립니다"는 쓰지 않는다.** 쇼츠에서 그 문장은 이탈 트리거다.
대신 **댓글에 쓰고 싶게 만드는 질문** 하나로 끝낸다.

| 좋은 CTA | 나쁜 CTA |
|---|---|
| "여러분 회사는 몇 단계까지 가요?" | "구독 좋아요 부탁드려요" |
| "이거 겪어본 사람 손" | "다음 영상에서 만나요" |
| "이거보다 심한 거 있으면 댓글로 이겨보세요" | "도움이 되셨길 바랍니다" |
| "1번이에요 2번이에요?" (양자택일) | "더 궁금한 점은 댓글로" |

**양자택일 질문**이 댓글 전환율이 가장 좋다. 고민할 필요 없이 숫자 하나만 치면 되기 때문이다.

---

## 5. 업로드 전 자가 검수 7문항

하나라도 ❌면 업로드하지 않는다.

- [ ] 1. 첫 3초에 인사·자기소개·로고가 없는가
- [ ] 2. 첫 문장에 **구체적 시간/직급/장소** 중 하나가 들어갔는가
- [ ] 3. 전체 글자수가 210~240자 범위인가 (45초 기준)
- [ ] 4. BODY가 3블록으로 나뉘고, 뒤로 갈수록 세지는가
- [ ] 5. 마지막이 **질문**으로 끝나는가
- [ ] 6. 특정 실존 회사·인물을 식별할 수 있는 디테일이 없는가
- [ ] 7. (정보형만) 출처가 `templates/script.md`에 채워졌는가
