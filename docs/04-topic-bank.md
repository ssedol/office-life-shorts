# 04. 주제 뱅크

> ⚠️ **주제의 단일 진실은 `data/topics.yaml` 이다.** 파이프라인(수집·선별)이 읽고 쓰는 건
> 그 파일이고, 이 문서는 카테고리 감각과 발굴 루틴을 설명하는 해설이다.
> 주제를 추가·수정할 때는 `data/topics.yaml` 을 고친다.

## 사용법

1. `data/topics.yaml` 에서 `status: idea` 인 주제를 하나 고른다.
2. `./scripts/new.sh -c <축> -t <주제ID> "<주제>"` 실행.
3. 해당 항목의 `status` 를 `scripted` 로 바꾼다.
4. **한 주제를 3축으로 확장**할 수 있으면 `docs/01` 4번 항목대로 시리즈화한다.

축 표기: **A**=공감 / **B**=꿀팁 / **C**=정보

## 주제 발굴 루틴 (뱅크가 비어갈 때)

1. **자기 채널 댓글** — 1순위. 시청자가 직접 쓴 사례가 그대로 다음 대본이다.
2. **블라인드·직장인 커뮤니티 인기글** — 소재만 참고하고 **문장은 절대 그대로 쓰지 않는다** (저작권).
3. **검색어** — 네이버·구글에 "연차", "퇴직금" 입력 시 뜨는 자동완성 = 실제 수요.
4. **본인/지인 이번 주 실제 사건** — 디테일이 가장 살아 있다.
5. **잘된 영상의 3축 확장** — 조회수 터진 주제는 반드시 나머지 2축으로 다시 만든다.
