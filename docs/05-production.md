# 05. 제작 규칙

## 1. 화면 규격

| 항목 | 값 |
|---|---|
| 해상도 | 1080 x 1920 (9:16) |
| 프레임 | 30fps (충분함. 60fps는 용량만 늘어남) |
| 길이 | 35~50초 기본 / 정보형만 최대 59초 |
| 안전 영역 | **상단 15%, 하단 25%는 비워둔다** |

### 안전 영역이 중요한 이유
쇼츠 플레이어는 하단에 제목·채널명·설명이, 우측에 좋아요·댓글·공유 버튼이 겹쳐 올라온다.
자막을 하단에 깔면 **가려진다.** 핵심 자막은 **화면 세로 중앙 ~ 중상단**에 배치한다.
우측 끝 약 15%도 버튼과 겹치므로 피한다.

```
┌─────────────┐
│   상단 15%   │ ← 비움 (기기 노치/상단 UI)
├─────────────┤
│             │
│  핵심 자막   │ ← 여기
│    영역      │
│             │  ← 우측 15%는 버튼 영역, 피함
├─────────────┤
│   하단 25%   │ ← 비움 (제목/채널명/CTA UI)
└─────────────┘
```

## 2. 자막 규칙

- **전 구간 자막 필수.** 무음 시청자 비중이 높다. 자막 없으면 그 시청자는 100% 이탈.
- 한 화면에 **최대 2줄, 줄당 12자 내외.** 길면 못 읽고 넘긴다.
- 폰트: 굵은 고딕 (Pretendard Bold, 나눔스퀘어 ExtraBold 등). 명조·손글씨 금지.
- 테두리(외곽선) 또는 그림자 필수 — 배경 밝기와 무관하게 읽혀야 한다.
- **강조어만 색을 바꾼다.** (기본 흰색 + 강조 노란색). 세 번째 색은 쓰지 않는다.
- 자막은 말보다 **0.1~0.2초 먼저** 뜬다. 늦게 뜨면 느리게 느껴진다.

## 3. 컷 리듬

- **2~3초마다 화면 변화.** 화면 전환, 확대, 자막 교체, 인서트 중 뭐든 하나.
- 같은 화면이 4초 이상 지속되면 그 지점에서 이탈이 생긴다.
- 전환 효과는 **하드컷 기본.** 페이드·와이프는 느려 보인다.
- 첫 프레임에 이미 자막+화면이 채워져 있어야 한다. 검은 화면에서 시작 금지.

## 4. 영상 소스 옵션

| 방식 | 장점 | 단점 | 추천 |
|---|---|---|---|
| 실사 연기 (본인/지인) | 공감축에 압도적. 차별화 최상 | 부담, 시간 | ⭐ 장기적으로 최선 |
| 얼굴 없이 손·모니터·책상만 | 부담 적고 현실감 있음 | 표정 못 씀 | ⭐ 현실적 출발점 |
| 캐릭터/일러스트 애니 | 톤 일관, 익명성 | 제작 시간 김 | 중간 |
| 스톡영상 + TTS | 가장 빠름 | **양산형으로 보임. 차별화 0** | 비추천 |

> 판단: 초기에는 **"얼굴 없이 책상·손·모니터 + 본인 육성"** 조합이 제작 부담 대비 차별화가 가장 좋다.
> TTS를 쓰더라도 **최소한 나레이션 억양은 자연스러운 것**으로 하고, 스톡영상 전면 사용은 피한다.

## 5. 오디오

- **BGM은 반드시 저작권 안전한 것만.** YouTube 오디오 보관함 또는 정식 라이선스.
  - 수익 창출 계정에서 저작권 클레임이 붙으면 해당 영상 수익이 전부 원저작자에게 간다.
- BGM 볼륨은 나레이션 대비 **-18dB 이하.** 음악이 들리면 이미 크다.
- 효과음은 **강조 지점 1~2회만.** 남발하면 싸구려로 들린다.
- 나레이션 음량 정규화: 라우드니스 -14 LUFS 근처.

## 6. 템포 튜닝

편집 완료 후 **1.05~1.1배속**을 걸어본다. 대부분의 쇼츠는 약간 빠를 때 더 잘 붙는다.
단, 정보형에서 숫자를 말하는 구간은 배속하지 않는다.

## 7. 제작 체크리스트

- [ ] 첫 프레임에 자막이 이미 떠 있는가
- [ ] 하단 25% / 우측 15%에 중요한 요소가 없는가
- [ ] 전 구간 자막이 있는가
- [ ] 4초 이상 정지된 화면이 없는가
- [ ] BGM이 나레이션을 가리지 않는가
- [ ] BGM·폰트·이미지가 전부 라이선스 확인되었는가
- [ ] 실존 인물·회사를 특정할 수 있는 요소(사번, 로고, 실명)가 없는가
- [ ] 무음으로 한 번 끝까지 봤는가 (이해되면 통과)
