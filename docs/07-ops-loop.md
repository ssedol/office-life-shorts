# 07. 운영 루프

## 1. 업로드 주기

| 단계 | 기간 | 주기 | 목표 |
|---|---|---|---|
| 0. 비축 | 업로드 전 2주 | — | **10개 미리 만들어 둔다** (초반 중단 방지) |
| 1. 탐색 | 1~30번째 영상 | 주 5회 | 어떤 축·주제가 먹히는지 찾기. 퀄리티보다 **횟수** |
| 2. 집중 | 31~80번째 | 주 4회 | 먹힌 포맷을 반복. 시리즈화 |
| 3. 확장 | 81번째~ | 주 3회 + 롱폼 실험 | 수익화·롱폼 전환 |

**탐색 단계에서 완벽주의가 최대 적이다.** 30개를 채우기 전에는 채널의 정답을 알 수 없다.

## 2. 보는 지표 (우선순위 순)

| 순위 | 지표 | 기준 | 의미 |
|---|---|---|---|
| 1 | **평균 조회율(시청 지속률)** | 60% 이상이면 양호 | 본문이 버티는가 |
| 2 | **3초 이탈률** | 40% 이하 목표 | 후킹이 먹혔는가 |
| 3 | **댓글 수 / 조회수** | 0.5% 이상이면 좋음 | 공감축이 작동했는가 |
| 4 | 좋아요 / 조회수 | 4% 이상 | 만족도 |
| 5 | 구독 전환 | — | 꿀팁축이 작동했는가 |
| — | 조회수 | **단독으로 판단하지 않음** | 결과일 뿐 원인이 아님 |

> 조회수만 보면 개선이 안 된다. **조회수가 낮은 이유가 3초 이탈인지, 본문 이탈인지를 봐야** 다음에 고칠 게 나온다.

## 3. 진단표

| 증상 | 원인 | 조치 |
|---|---|---|
| 노출은 되는데 조회율 30%대 | 후킹 실패 | `docs/03` 패턴으로 첫 3초 전면 재작성 |
| 3초는 넘기는데 15초에서 급락 | SETUP이 늘어짐 | BODY를 5초 앞으로 당김 |
| 끝까지 보는데 댓글 0 | CTA 부재/약함 | 양자택일 질문으로 교체 |
| 조회수는 나오는데 구독 0 | 공감축만 있음 | 꿀팁축 비중 상향 |
| 노출 자체가 안 뜸 | 주제 수요 없음 | 주제 뱅크 재선정 (검색 수요 확인) |

## 4. 30일 리뷰 (월 1회)

1. 상위 3개 / 하위 3개 영상을 뽑는다.
2. 각각 **축(A/B/C), 후킹 패턴, 길이, 카테고리**를 표로 정리한다.
3. 상위 3개의 **공통점 1개**를 찾아 다음 달 기본값으로 삼는다.
4. 하위 3개는 **같은 주제를 다른 후킹으로 재제작**한다 (주제 문제인지 후킹 문제인지 분리).

## 5. 리스크 관리

- **정보형 정정 프로토콜**: 오류 발견 시 ① 영상 비공개 전환 ② 고정 댓글로 정정 ③ 정정 영상 재업로드. 조용히 지우지 않는다.
- **저작권**: BGM·폰트·이미지 라이선스 근거를 `output/` 대본 파일에 기록해 둔다. 클레임 시 소명 자료가 된다.
- **명예훼손**: 실존 인물·회사 특정 금지. 커뮤니티 글을 소재로 쓸 때 **문장을 그대로 옮기지 않는다.**
- **번아웃**: 비축분 5개 밑으로 내려가면 업로드 주기를 줄인다. 채널이 멈추는 것보다 낫다.
