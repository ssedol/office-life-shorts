# 06. 업로드 메타데이터

## 1. 제목

쇼츠 제목은 **피드에서 하단에 한 줄로 잘려 보인다.** 그래서 규칙이 롱폼과 다르다.

- 길이: **공백 포함 25자 이내** (넘으면 잘려서 핵심이 사라짐)
- **핵심 단어를 앞쪽 12자 안에** 배치
- 제목은 후킹 문장의 축약형이지, 요약문이 아니다

### 제목 공식 4종

| 공식 | 예시 |
|---|---|
| 대상 + 상황 | `팀장이 한숨 쉴 때 하면 안 되는 것` |
| 손해 경고 | `연차 안 쓰고 퇴사하면 생기는 일` |
| 숫자 예고 | `퇴사 전 꼭 챙길 것 4가지` |
| 반전 선언 | `보고서 반려, 내용 문제가 아닙니다` |

### 제목 금지
- ❌ 낚시성 과장 (`충격`, `경악`, `이것만 보면 인생 바뀜`) → 클릭은 되고 체류는 안 됨 → 알고리즘 역효과
- ❌ 제목에 `#shorts` 넣기 → 글자수 낭비 (설명란에 넣는다)
- ❌ 이모지 3개 이상

## 2. 해시태그

- **설명란 첫 줄에 `#shorts`** 는 넣는다 (관례상 유지. 없어도 쇼츠 판정은 되지만 손해 볼 게 없음)
- 총 **3~5개**. 그 이상은 의미 없고 스팸으로 보인다.
- 고정 2개 + 주제 2개 구성:
  ```
  고정: #shorts #직장생활
  주제: #연차  #퇴사    (해당 영상 주제)
  ```
- 채널 고유 태그를 하나 만들어 전 영상에 붙인다 (예: `#직장인생존기`). 나중에 시리즈 묶기에 쓰인다.

## 3. 설명란 템플릿

```
#shorts #직장생활 #(주제태그1) #(주제태그2) #직장인생존기

(후킹 문장 한 줄 그대로)

▶ 이런 상황 겪어보셨나요? 댓글로 알려주세요.

※ 본 영상의 사례는 일반적인 상황을 각색한 것이며 특정 인물·회사와 무관합니다.
(정보형만) ※ 개인의 근로 형태에 따라 적용이 다를 수 있습니다. 정확한 판단은 고용노동부 상담(1350)을 이용하세요.
```

## 4. 고정 댓글 (필수)

업로드 직후 **본인 댓글을 달고 고정**한다. 댓글창 최상단이 비어 있으면 첫 댓글이 안 달린다.

- 내용은 **답하기 쉬운 질문 하나**. 영상 CTA와 동일하게.
- 예: `1번이에요 2번이에요? 저는 솔직히 2번...`
- 반대로 **본인 홍보/구독 요청은 고정 댓글에 쓰지 않는다.** 대화가 끊긴다.

## 5. 썸네일

쇼츠는 피드 소비가 대부분이라 썸네일 영향이 롱폼보다 작지만, **채널 방문 시 그리드**에서는 결정적이다.
- 그리드에서 **제목 6~8자가 크게** 읽혀야 한다
- 채널 전체 썸네일의 **색 톤을 통일**한다 (방문자가 시리즈로 인식)
- 영상 첫 프레임을 그대로 쓰지 말고 별도 지정

## 6. 업로드 타이밍

일반 가이드라인은 **평일 저녁(KST 19~22시)** 이지만, 이건 출발점일 뿐이다.
→ 30개 업로드 후 **본인 채널 애널리틱스의 "시청자가 유튜브를 이용하는 시간대"** 를 보고 재조정한다.
일반론보다 자기 채널 데이터가 항상 우선한다.

## 7. 업로드 전 최종 체크

- [ ] 제목 25자 이내 & 핵심어가 앞 12자 안
- [ ] 해시태그 3~5개, `#shorts` 포함
- [ ] 설명란 면책 문구 포함 (정보형이면 상담 안내까지)
- [ ] 고정 댓글 준비됨
- [ ] 썸네일 별도 지정
- [ ] 아동용 콘텐츠 = 아니오 설정
- [ ] `output/` 대본 파일에 업로드 URL과 날짜 기록
