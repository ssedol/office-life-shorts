# 팀장이 한숨 쉴 때 하면 안 되는 것

> **이 파일은 시스템 동작을 보여주는 샘플입니다.** 실제 1번 영상으로 써도 되고, 지우고 새로 시작해도 됩니다.

## 1. 브리핑

| 항목 | 내용 |
|---|---|
| 타겟 상황 | 월요일 오전, 팀 분위기가 싸해서 보고 타이밍을 못 잡고 있는 상태 |
| 시청자 감정 (전 → 후) | 눈치보임·불안 → "나만 그런 게 아니네" + 약간의 이해 |
| 핵심 한 문장 | 팀장의 한숨은 대부분 나 때문이 아니다 |
| CTA 질문 | 당신 팀장은 몇 단계까지 가는가 (숫자 답변형) |

## 2. 후킹 후보 (3개 이상, 버린 것도 남긴다)

1. (①시각 고정) "월요일 아침, 팀장이 모니터 보면서 한숨 쉬면 그때 절대 하면 안 되는 게 있어요."
2. (③오답 파괴) "팀장 기분 안 좋을 때 '괜찮으세요?' 물어보는 거, 그게 제일 위험해요."
3. (⑦금기 폭로) "팀장 한숨 소리 단계별로 구분하는 거, 다들 하고 있잖아요."

→ **채택: 1번** — 시각·행동이 둘 다 구체적이고, "하면 안 되는 게 있어요"로 답을 안 줘서 궁금증이 남는다. 2번은 답을 다 줘버려서 나갈 이유가 생긴다.

## 3. 대본

| 0.0–3.0 HOOK | 월요일 아침, 팀장이 모니터 보면서 한숨 쉬면 그때 절대 하면 안 되는 게 있어요. | 0.0초부터 자막 떠 있음. 모니터 앞 뒷모습 / 자막 「**월요일 아침 팀장 한숨**」 |
| 3.0–8.0 SETUP | 다들 눈치 보면서 괜찮으세요 물어보잖아요. 그게 제일 위험해요. | 말풍선 「괜찮으세요?」 → 빨간 X 오버레이 |
| 8.0–15.0 BODY ① | 1단계는 그냥 한숨이에요. 이건 피곤한 거라 말 걸어도 돼요. | 화면 좌측에 「1단계」 큰 자막 / 초록색 신호 |
| 15.0–22.0 BODY ② | 2단계는 마우스를 세게 놓는 소리. 여기서부터 보고는 미뤄야 돼요. | 「2단계」 / 마우스 놓는 손 클로즈업 + 효과음 / 노란색 |
| 22.0–30.0 BODY ③ | 3단계는 말없이 자리에서 일어나 나가요. 이때 따라 나가면 그날 하루가 날아갑니다. | 「3단계」 / 빈 의자 / 빨간색 |
| 30.0–40.0 PAYOFF | 근데 웃긴 게, 그 한숨 대부분 우리 때문이 아니에요. 팀장도 위에서 깨지고 내려온 거거든요. | 화면 전환(톤 다운) / 자막 「**우리 때문이 아님**」 |
| 40.0–45.0 CTA | 여러분 팀장은 몇 단계까지 가요? 3단계면 댓글에 3. | 자막 「1 · 2 · 3 ?」 크게 |
