# 썸네일 생성 프롬프트 — 2026-09-21 (2편)

1편 썸네일과 같은 틀을 쓴다. **채널이 한 눈에 알아보이는 게 목적**이므로
글자 위치·배지·외곽선 두께를 매번 바꾸지 않는다. 바뀌는 건 문구와 표정뿐이다.

## 1편에서 가져오는 고정 요소

| 요소 | 규격 |
|---|---|
| 상단 문구 | 2줄, 흰 글자 + 아주 굵은 검정 외곽선, **핵심 단어 1개만 노랑** |
| 배지 | 검정 알약 모양 + 흰 글씨 `직장인 공감`, 문구 바로 아래 오른쪽 |
| 인물 | 가슴 위 클로즈업, 화면의 아래 2/3 차지 |
| 말풍선 | 작고 둥근 흰 풍선, 짧은 한마디 |
| 강조 기호 | 빨강·검정 짧은 직선, 느낌표 |
| 배경 | 노란 사무실 (본편과 동일) |

## 쓰는 법

마스터 캐릭터 이미지를 첨부하고 아래를 통째로 붙여넣는다.

```
첨부한 이미지가 내 유튜브 채널의 확정된 캐릭터야.
이 캐릭터로 유튜브 쇼츠 썸네일 한 장을 만들어줘.

■ 규격
- 세로 9:16 (1080 x 1920)
- 한 장만. 여러 시안을 격자로 묶지 마.

■ 캐릭터 (첨부 이미지 그대로)
얼굴, 머리 모양, 옷, 색, 선 굵기를 새로 해석하지 말고 그대로 재현해.
정수리에 삐죽 솟은 머리카락, 양 볼의 분홍 홍조,
흰 와이셔츠 + 진한 네이비 넥타이 + 파란 줄 사원증 — 이 네 가지는 반드시 유지해.
플랫 벡터 일러스트, 굵고 일정한 검정 외곽선, 음영 거의 없음.

■ 배경
밝은 레몬 옐로우 벽의 사무실. 왼쪽에 창문(하늘색 하늘, 흰 구름, 파란 빌딩),
오른쪽 위에 흰색 원형 벽시계. 배경은 연하고 살짝 흐릿하게 처리해서
글자와 캐릭터가 도드라지게 해.

■ 화면 구성 (위에서부터)

1) 상단 — 큰 문구 2줄
화면 위쪽 30% 안에 두 줄로 크게 넣어줘.

   첫째 줄:  이 말만 하면
   둘째 줄:  야근 확정

- 아주 굵은 한국어 고딕체.
- 글자는 흰색, 외곽선은 아주 굵은 검정. 글자 크기 대비 외곽선이 확실히 두껍게.
- **"야근" 이 두 글자만 선명한 노란색**으로 칠하고, 나머지는 흰색.
- 두 줄 모두 화면 폭을 꽉 채울 만큼 크게. 썸네일이 작게 보여도 읽혀야 해.
- 글자 뒤에 옅은 검정 그림자를 깔아 노란 배경에서 떠 보이게 해.
- 오탈자 없이 정확히 위 문구 그대로 써줘.

2) 문구 바로 아래 오른쪽 — 작은 배지
검정색 알약 모양(둥근 모서리 직사각형) 안에 흰 글씨로 `직장인 공감`.
문구보다 훨씬 작게, 오른쪽에 붙여서.

3) 가운데 — 캐릭터
가슴 위 클로즈업. 화면 중앙~아래를 차지하게 크게.
표정이 이 썸네일의 핵심이야:
- 눈은 크고 둥근 검정 타원으로 활짝 뜨고
- 입은 크게 벌려 "네!" 하고 대답하는 모양
- 눈썹은 위로 올라가 밝고 씩씩한 표정
아무 생각 없이 시원하게 대답하는 얼굴이어야 해. 걱정하거나 찡그리면 안 돼.
한 손을 얼굴 옆으로 들어 가볍게 경례하듯 대답하는 제스처.

4) 캐릭터 얼굴 옆 — 말풍선
작고 둥근 흰색 말풍선에 검정 글씨로 정확히 이렇게:

   네, 알겠습니다!

캐릭터 문구보다 훨씬 작게. 꼬리가 캐릭터 입을 향하게.

5) 오른쪽 아래 — 서류를 내미는 손
화면 오른쪽 가장자리에서 다른 사람의 팔이 들어와 흰 서류 뭉치를 내밀고 있어.
**얼굴과 몸은 절대 그리지 마.** 연회색 와이셔츠 소매와 손만.
손 주변에 빨간 짧은 직선 3개로 강조.

6) 강조 기호
- 캐릭터 머리 옆에 검정 짧은 직선 3개
- 상단 문구 오른쪽 끝에 빨간 느낌표 2개

■ 절대 하지 말 것
- 위에 적은 문구(`이 말만 하면`, `야근 확정`, `직장인 공감`, `네, 알겠습니다!`)
  외에 다른 글자, 숫자, 로고, 워터마크를 넣지 마.
- 영어를 넣지 마.
- 다른 사람의 얼굴을 그리지 마.
- 캐릭터를 새로 해석하지 마.
```

## 받은 뒤 확인

- **글자가 정확한가.** 이미지 생성 모델은 한글을 자주 틀린다.
  `야근 확정`의 받침이 깨지거나 글자가 뭉개지면 다시 뽑는다.
- **작게 줄여도 읽히는가.** 실제로는 폰 화면에서 손톱만 하게 보인다.
  이미지를 20% 크기로 줄여놓고 문구가 읽히는지 본다.
- **아래 25%에 중요한 게 없는가.** 쇼츠 피드에서 그 자리에 제목과 조회수가 깔린다.
