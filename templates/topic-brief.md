# 주제 입력 폼

대본 생성 전에 이 6칸만 채운다. 여기가 비어 있으면 대본이 흐려진다.

```yaml
주제:          # 예) 팀장이 한숨 쉴 때 하면 안 되는 것
축:            # A(공감) / B(꿀팁) / C(정보)
타겟 상황:     # 시청자가 이 영상을 볼 때 처한 상태. 예) 월요일 오전, 팀 분위기가 싸한 상태
시청자 감정:   # 영상 시작 시 감정 → 끝났을 때 감정. 예) 눈치보임 → "나만 그런 게 아니네"
핵심 한 문장:  # 이 영상이 남기는 단 하나의 문장 (없으면 만들지 않는다)
CTA 질문:      # 댓글에 답하게 만들 질문. 양자택일 우선
```

## 정보형(C)만 추가

```yaml
근거 법령/기관:   # 예) 근로기준법 제60조
출처 URL:         # 1차 출처. 블로그 금지
확인 날짜:        # 법령은 개정된다
예외 조건:        # 이 정보가 적용되지 않는 경우
```
